## Scope and retained limitations

Actual accepted focused scenarios include MP3/WAV/FLAC audio, MAIN/cue
listening, scratch, CUE/PLAY/Master Tempo, manual loop OUT/half/double/exit,
combined scratch/MT, local cue save/reload/reboot/delete, normal D1 LOAD lock,
stopped USB storage/controller reconnect and reboot/OTA recovery.

Remaining deck/format combinations, shifted/touch load-lock variants,
source-cue tombstone reimport/cross-media physical isolation and active
removal/cancellation variants remain NOT RUN. Host coverage is retained and
is not claimed as physical acceptance. JC1060, DDJ-400, other controllers and
real Pro DJ Link peer interoperability remain outside this hardware release.
Recorder and SD experiments remain disabled. Security eFuse provisioning and
Secure Boot/Flash Encryption are unchanged; signed OTA is not such provisioning.
