## Focused correction

The waveform strip is `(648 + 2 * 128) * 141 * 2` bytes, aligned to 254,976.
Its allocator unnecessarily tried internal DMA first, then PSRAM. Both deck
strip allocations therefore produced the observed failures. Allocate these
cache-aligned PPA source buffers directly in PSRAM; retain the existing PSRAM
fallback and never consume internal DMA memory for a strip.

The status handler's 2 KiB USB JSON array occupied the 8 KiB HTTP task stack.
Allocate that bounded request-owned buffer in PSRAM and release it on every
later error/success path. Keep HTTP task size unchanged and do not move audio
or USB DMA allocations. Existing Web Remote JSON fields remain compatible.

Correction software checks passed: full Windows host runner, ESP-IDF 6.0.2
JC4880 ordinary and JC1060 preview builds, both product screenshot gates (34 unchanged
captures), board/identity/budget validators, unchanged locks and clean diff.
The corrected build must still be made fresh from its pushed SHA, signed and
checked on the installed device. The first candidate remains physically
unaccepted. Do not publish it.
