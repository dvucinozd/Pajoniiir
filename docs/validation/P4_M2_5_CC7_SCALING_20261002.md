The table runtime adds `cc7_to14` (raw type 8) for 7-bit absolute CCs feeding
14-bit PITCH semantics. Integer scaling preserves 0, center 64 and 127 as
0, 8192 and 16383. Mixer snapshots retain scaled values; tempo is not replayed.
Existing raw CC7 Beat FX depth and CC14 pairing are unchanged.

New entries require S3CP v3. The parser still accepts v2 and rejects v1.
Both compilers continue to emit v2 for profiles without scaled controls.
The installed M2.4 firmware rejects v3; do not overwrite its working v2
profiles before installing a firmware that supports the extension.

The coordinated Web Profile Builder exporter includes 27 of the DJ2GO2
inventory's 59 controls, compared with 20 before this change (512 bytes,
previously 400). Additions cover both tempos, both trims, crossfader, master
and headphone level. Unsupported controls remain listed in the omission report.
FLX4, FLX10 and REV7 outputs remain v2; REV1 still lacks USB identity.

Numark tempo retains the source transform metadata. Its negative Mixxx pitch
expression and P4's `(8192 - pitch)` convention have the same direction, so
no second inversion is applied. Unlike the source MSB-only shift, this
projection deliberately expands the positive input half to the full P4 range.
The center and direction are preserved; physical endpoint/direction checks
remain required. Reference: [Mixxx MIDI pitch helper](https://github.com/mixxxdj/mixxx/blob/main/res/controllers/common-controller-scripts.js).
