01 · Start

Quick start

Brzi početak

The P4 is the sole runtime authority. It plays the tracks, owns deck/mixer state, drives the display and communicates directly with the FLX4 — no performance computer is required.

P4 je jedini runtime autoritet. Reproducira glazbu, vodi stanje deckova i mixera, upravlja zaslonom i izravno komunicira s FLX4 — računalo nije potrebno tijekom nastupa.

Connect audio. Connect the Pajoniiir MAIN RCA output to your amplifier/mixer. Connect headphones to the DDJ-FLX4 for cue/monitor.
Connect the controller. Connect the Pioneer DDJ-FLX4 to USB1.
Insert music. Insert the Rekordbox-exported USB storage medium into USB0.
Power on. Use the approved regulated power arrangement and wait until the display and USB roots are ready.
Open Library. Rotate the FLX4 Browse encoder to select a track, then press LOAD 1 or LOAD 2.
Play. Use PLAY/CUE, jogs, tempo, mixer and headphone-cue controls normally. Confirm MAIN and cue levels before raising the PA.
Spoji audio. Spoji Pajoniiir MAIN RCA izlaz na pojačalo/mikser. Slušalice spoji na DDJ-FLX4 za cue/monitor.
Spoji kontroler. Pioneer DDJ-FLX4 spoji na USB1.
Umetni glazbu. Rekordbox-exportirani USB medij umetni u USB0.
Uključi uređaj. Koristi odobreno regulirano napajanje i pričekaj da zaslon i oba USB root porta budu spremni.
Otvori Library. Browse enkoderom na FLX4 odaberi pjesmu, zatim pritisni LOAD 1 ili LOAD 2.
Pokreni reprodukciju. Koristi PLAY/CUE, jogove, tempo, mixer i headphone-cue kontrole. Prije podizanja razine PA sustava provjeri MAIN i cue glasnoću.

03 · UI

On-device display

Zaslon uređaja

The P4 LVGL interface provides Overview, Library, Hot Cues and Settings screens. The Browse encoder also participates in UI navigation.

P4 LVGL sučelje ima ekrane Overview, Library, Hot Cues i Settings. Browse enkoder sudjeluje i u navigaciji kroz sučelje.

Browse rotate

Moves the Library selection. In supported Overview contexts it can also control waveform navigation/zoom behavior.

Pomiče odabir u Libraryju. U podržanim Overview kontekstima koristi se i za navigaciju/zoom waveform prikaza.

Browse press

Toggles the UI between Library and Overview. It does not load a deck.

Prebacuje UI između Library i Overview prikaza. Ne učitava pjesmu u deck.

LOAD 1 / LOAD 2

Loads the currently selected Library track into Deck 1 or Deck 2.

Učitava trenutačno odabranu pjesmu iz Libraryja u Deck 1 ili Deck 2.

04 · FLX4

Core controls

Glavne kontrole

The current standalone mapping uses the FLX4 as the operator surface while the P4 owns playback and mixer state.

U trenutačnom standalone mappingu FLX4 je operatorska površina, dok P4 vodi playback i mixer stanje.

PLAY / PAUSE

Starts or pauses the selected deck.

Pokreće ili pauzira odabrani deck.

CUE

Back-cue / default cue behavior.

Back-cue / standardno cue ponašanje.

JOG

Platter touch supports scratch; platter/side movement supports pitch bend. SHIFT+jog search is implemented.

Dodir plattera podržava scratch; pomak plattera/ruba podržava pitch bend. SHIFT+jog search je implementiran.

TEMPO

Per-deck pitch. SHIFT+Beat Sync cycles ±6%, ±10% and ±16% ranges; default is ±10%.

Pitch po decku. SHIFT+Beat Sync mijenja raspon ±6%, ±10% i ±16%; početni raspon je ±10%.

BEAT SYNC

Matches BPM to the other deck and performs one-shot beat-phase alignment when beatgrids are available. Continuous follow is not implemented.

Usklađuje BPM s drugim deckom i radi jednokratno fazno poravnanje beata kada postoje beatgrid podaci. Kontinuirano praćenje nije implementirano.

LOOPS

Loop In, Loop Out, Reloop/Exit, halve and double are implemented. Beat jump and several shifted loop functions exist but some remain hardware-smoke pending.

Loop In, Loop Out, Reloop/Exit, halve i double su implementirani. Beat jump i neke SHIFT loop funkcije postoje, ali dio njih još čeka završni hardware smoke.

05 · Media

Rekordbox USB library

Rekordbox USB biblioteka

USB0 is dedicated to the Rekordbox storage medium. The P4 reads the exported library and analysis data, exposes tracks in Library, and uses available BPM/beatgrid/waveform/cue information.

USB0 je namijenjen Rekordbox mediju. P4 čita exportiranu biblioteku i analysis podatke, prikazuje pjesme u Libraryju te koristi dostupne BPM/beatgrid/waveform/cue informacije.

Current validated baseline

Trenutačno validirana baza

MP3 is the repeatedly exercised playback baseline on the current candidate, including dual-deck and long-duration tests.

MP3 je višestruko testirana playback baza trenutačnog kandidata, uključujući dual-deck i višesatne testove.

Still under release qualification

Još u release kvalifikaciji

WAV / FLAC mixed-format physical playback and final acceptance remain open release gates. Do not treat them as release-qualified yet.

WAV / FLAC mixed-format fizička reprodukcija i završni acceptance još su otvoreni release gateovi. Nemoj ih još smatrati release-qualified formatima.

For best results, prepare the medium with Rekordbox export before use. Do not remove USB0 while a track is loading unless you are intentionally testing recovery behavior.

Za najbolje rezultate pripremi medij kroz Rekordbox export. Nemoj vaditi USB0 tijekom učitavanja pjesme osim ako namjerno testiraš recovery ponašanje.

06 · Network

Wi-Fi Remote & signed OTA

Wi-Fi service is controlled from P4 Settings and is intended for service, diagnostics, controller-profile operations and signed firmware update.

Wi-Fi servis uključuje se iz P4 Settingsa i služi za servis, dijagnostiku, controller-profile operacije i potpisanu nadogradnju firmwarea.

Connect to the local service

Spajanje na lokalni servis

2. SSID: Pajoniiir

Firmware update

Nadogradnja firmwarea

Upload only a signed main-deck-p4.ddjota package. Keep power stable and do not play audio during the update. Wait for a clean reboot, reconnect, then verify the version, USB library, FLX4 control/LED state, MAIN and headphone cue.

Uploadaj samo potpisani main-deck-p4.ddjota paket. Tijekom nadogradnje napajanje mora biti stabilno i nemoj reproducirati audio. Pričekaj uredan reboot, ponovno se spoji te provjeri verziju, USB biblioteku, FLX4 kontrole/LED stanje, MAIN i headphone cue.

OTA safety: never upload a raw .bin through the signed web-update path. Raw images are reserved for wired recovery/defined transition procedures. An interrupted transfer should leave the current slot bootable, but stable power is still mandatory.
OTA sigurnost: nikada ne uploadaj sirovi .bin kroz potpisani web-update put. Raw image služi za wired recovery/definirane prijelazne procedure. Prekinuti transfer trebao bi ostaviti trenutačni slot bootabilnim, ali stabilno napajanje je i dalje obavezno.
07 · Care

Power, shutdown and handling

Napajanje, gašenje i rukovanje

Before power-up

Prije uključivanja

Verify the approved supply, common ground and protected USB VBUS arrangement. Final enclosure wiring must be separately qualified.

Provjeri odobreno napajanje, zajedničku masu i zaštićeni USB VBUS. Finalno ožičenje u kućištu mora proći zasebnu kvalifikaciju.

Before power-off

Prije gašenja

Stop playback and make sure no OTA or service write is active. Avoid removing media during a load/write operation.

Zaustavi reprodukciju i provjeri da OTA ili servisni write nije aktivan. Izbjegavaj vađenje medija tijekom load/write operacije.

Transport

Transport

Disconnect USB and RCA cables before moving the unit. Protect connectors from lateral load and keep ventilation paths clear.

Prije pomicanja odspoji USB i RCA kabele. Zaštiti konektore od bočnog opterećenja i ostavi ventilacijske otvore slobodnima.

08 · Support

Troubleshooting

Rješavanje problema

The Library is empty or USB0 is not detectedLibrary je prazan ili USB0 nije prepoznat

Confirm the Rekordbox medium is in USB0, not USB1. Re-seat the medium once, wait for the mount/library refresh, and confirm the device has a valid Rekordbox export. If the problem follows the medium, test another known-good export.

Provjeri da je Rekordbox medij u USB0, ne u USB1. Jednom ga izvadi i ponovno umetni, pričekaj mount/library refresh te potvrdi da medij sadrži valjani Rekordbox export. Ako problem prati medij, testiraj drugi poznato ispravan export.

The FLX4 controls do not respondFLX4 kontrole ne reagiraju

Verify the FLX4 is on USB1. Confirm the controller is powered/enumerated and that the display/system is otherwise responsive. The current firmware has validated reconnect recovery, so a controlled disconnect/reconnect can be used after stopping playback if needed.

Provjeri da je FLX4 na USB1. Potvrdi da je kontroler napajan/enumeriran i da ostatak sustava reagira. Trenutačni firmware ima validiran reconnect recovery pa se, nakon zaustavljanja playbacka, po potrebi može napraviti kontrolirani disconnect/reconnect.

There is no MAIN audioNema MAIN zvuka

Check Deck PLAY state, channel fader, crossfader, Trim and Master Level. MAIN program audio leaves through the Pajoniiir PCM5102A/RCA path — not the FLX4 headphone connector.

Provjeri PLAY stanje decka, channel fader, crossfader, Trim i Master Level. MAIN program izlazi kroz Pajoniiir PCM5102A/RCA put — ne kroz FLX4 headphone priključak.

There is no headphone cueNema headphone cue zvuka

Headphones belong on the FLX4. Enable CH1/CH2 CUE (PFL), then check Headphones Mix and Headphones Level. The cue/monitor path uses FLX4 USB-audio channels 3/4.

Slušalice trebaju biti na FLX4. Uključi CH1/CH2 CUE (PFL), zatim provjeri Headphones Mix i Headphones Level. Cue/monitor koristi FLX4 USB-audio kanale 3/4.

Wi-Fi Remote cannot be openedWi-Fi Remote se ne može otvoriti

Enable Wi-Fi Remote in Settings, connect the client to SSID Pajoniiir, then try http://192.168.4.1. Use pajoniiir.local only when mDNS resolution is available.

Uključi Wi-Fi Remote u Settingsu, spoji klijenta na SSID Pajoniiir, zatim otvori http://192.168.4.1. pajoniiir.local koristi samo kada radi mDNS rezolucija.

An OTA package is rejectedOTA paket je odbijen

Use the correct signed main-deck-p4.ddjota package. Wrong target, chip/project, key, signature, size, image hash, modified manifest or trailing data are intentionally rejected. Do not work around signature failures with a raw web upload.

Koristi ispravan potpisani main-deck-p4.ddjota paket. Pogrešan target, chip/project, ključ, potpis, veličina, image hash, izmijenjen manifest ili trailing podaci namjerno se odbijaju. Nemoj zaobilaziti signature grešku raw web uploadom.
