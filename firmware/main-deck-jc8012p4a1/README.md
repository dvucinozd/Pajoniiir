# JC8012P4A1 shared-core development target (SCAFFOLD)

Status: **scaffold only. Never built, never flashed, hardware NOT RUN.** Created
2026-10-13 before the board arrived. Read
[`docs/validation/jc8012p4a1/BOARD_NOTES.md`](../../docs/validation/jc8012p4a1/BOARD_NOTES.md)
first: it lists the sources, the schematic findings and the open questions.

- 10.1" panel, native 800x1280 portrait, UI 1280x800 landscape. JD9365 over MIPI-DSI with
  the Espressif component's default register table (unverified on the V3 unit).
- Touch GSL3680: **not integrated**. The UI runs display-only (`bsp_touch_init()` returns OK
  with no handle). The only driver found, `guition-jc/esp_lcd_touch_gsl3680` 0.1.0, requires
  ESP-IDF >=6.1.0 (this project pins 6.0.2) and ships a controller firmware table with no
  upstream licence, so it is neither vendored nor referenced yet.
- No Ethernet. Wi-Fi through the ESP32-C6, default ON, AP+STA, WPA2.
- USB: controller on the HS root 0 and storage on the FS root 1 behind a self-powered hub is
  an **assumption** copied from the JC1060; check on the unit.
- microSD on GPIO39-44 with the on-chip LDO channel 4, same as the shared BSP code.
- The UI has no 1280x800 layout yet (`ui_overview.c`, `ui_settings.c`, `ui.c` choose by width,
  800 or 1024). Expect a layout task before the screen is usable.
- No `dependencies.lock` yet: it is generated by the first (explicitly approved) build and
  must then be committed.

Build, only with an explicit GO, from this directory:
`idf.py -B build_jc8012p4a1 -D SDKCONFIG=build_jc8012p4a1/sdkconfig build`
then `tools/check_board_build.py --build ... --project main-deck-jc8012p4a1`.
